System Info Extractor

Простой и легковесный Python-скрипт для сбора базовой информации об операционной системе, сетевых настройках и окружении Python. Результат работы скрипта сохраняется в удобном для чтения и машинной обработки формате JSON.

🚀 Возможности

Скрипт собирает данные по трем основным направлениям:

🖥 Информации об ОС (OS Info):

-Тип операционной системы (Windows, Linux, MacOS и т.д.)

-Имя узла (node)

-Релиз и версия ОС

-Архитектура и тип процессора

🌐 Сетевая информация (Network Info):

-Имя хоста (hostname)

-Полное доменное имя (FQDN)

-Локальный IP-адрес

🐍 Информация о Python (Python Info):

-Версия Python

-Реализация (например, CPython)

-Компилятор и информация о сборке

🛠 Требования

Для работы скрипта требуется только Python 3.x.

Скрипт использует исключительно стандартные библиотеки Python (sys, platform, json, socket), поэтому установка дополнительных зависимостей через pip не требуется.

💻 Использование

-Скачайте скрипт (например, сохранив его как system_info.py).

-Откройте терминал или командную строку.

-Перейдите в директорию со скриптом и выполните команду:

python system_info.py


-После успешного выполнения в консоли появится сообщение: Информация сохранена в файл: system_info.json. Файл будет создан в той же директории, откуда был запущен скрипт.
